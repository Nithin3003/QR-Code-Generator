## 🔧 HOW THEY WORK

### Display Ads (300x250, 728x90, Native)
- Scripts load dynamically via useEffect
- useRef prevents duplicate loading
- Actual ad content injected by ad network
- Labels show "ADVERTISEMENT" or "SPONSORED CONTENT"

### Background Ads (Popunder, Vignette, Push)
- Load once per page
- Trigger automatically or on user action
- No visible UI until triggered
- Managed by ad network scripts
